# 🏴 CTF Write-ups

**Repositorio de análisis y documentación de retos Capture The Flag (CTF).**

Aquí organizaré write-ups por categoría, explicando el problema, la metodología, las herramientas empleadas, las evidencias y los aprendizajes obtenidos.

> **Estado:** estructura inicial. No se listan retos como resueltos hasta documentarlos y verificar sus resultados. Los write-ups solo se publicarán cuando las normas del reto o de la plataforma permitan divulgar soluciones.

## 📝 Formato de documentación

Cada reto incluirá contexto, objetivo, entorno permitido, herramientas, metodología, evidencias relevantes, resultado comprobado y aprendizajes. Hay una [plantilla reutilizable](templates/WRITEUP-TEMPLATE.md).

```text
CTF-Writeups/
├── README.md
├── Forensics/README.md
├── Cryptography/README.md
├── Steganography/README.md
├── Web/README.md
├── OSINT/README.md
└── templates/WRITEUP-TEMPLATE.md
```
